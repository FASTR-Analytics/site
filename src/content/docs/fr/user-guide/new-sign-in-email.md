FASTR vous envoie un e-mail lorsque quelqu'un, vous ou une autre personne, se connecte à votre compte depuis un appareil (par exemple un ordinateur ou un téléphone) que FASTR ne reconnaît pas. L'e-mail contient un seul bouton. Si vous appuyez sur ce bouton, cet appareil est déconnecté de FASTR.

## Si vous avez appuyé sur le bouton

L'appareil indiqué dans l'e-mail est maintenant déconnecté de FASTR. Le bouton agit immédiatement, sans vous demander de confirmation.

Si vous ne savez pas si la connexion vient de vous, lisez [Comment savoir si une connexion vient de vous](#comment-savoir-si-une-connexion-vient-de-vous). Si vous avez encore un doute, suivez les étapes prévues pour une connexion qui ne vient pas de vous.

### La connexion vient de vous

L'e-mail ne signifie pas que votre compte a un problème. Vous avez déconnecté votre propre appareil de FASTR, vous devez donc vous reconnecter. Vous n'avez pas besoin de changer votre mot de passe.

1. Allez à l'adresse web FASTR que vous utilisez d'habitude. Chaque pays a sa propre adresse, c'est pourquoi cette page ne l'indique pas.
2. Connectez-vous avec votre adresse e-mail et votre mot de passe.

Vous recevrez peut-être le même e-mail en vous reconnectant. Dans ce cas, n'appuyez pas sur le bouton.

### La connexion ne vient pas de vous

Quelqu'un d'autre s'est connecté à votre compte, et vous avez bien fait d'appuyer sur le bouton. L'appareil utilisé par cette personne est maintenant déconnecté de FASTR. Changez votre mot de passe dès maintenant, pour que cette personne ne puisse plus se connecter.

1. Allez à l'adresse web FASTR que vous utilisez d'habitude et connectez-vous.
2. Cliquez sur l'icône en forme de personne en haut à droite de la page, puis sur **Votre profil**.
3. Cliquez sur **Gérer le compte**, puis sur **Sécurité**.
4. Cliquez sur **Changer le mot de passe**. Si le formulaire demande votre mot de passe actuel, saisissez-le.
5. Saisissez votre nouveau mot de passe dans **Nouveau mot de passe**, puis une deuxième fois dans **Confirmer le mot de passe**.
6. Vérifiez que la case **Se déconnecter de tous les autres appareils** est cochée, puis cliquez sur **Sauvegarder**. Cette case est déjà cochée à l'ouverture du formulaire. Elle déconnecte tous les autres appareils connectés à votre compte.

Informez ensuite votre administrateur FASTR que quelqu'un d'autre s'est connecté à votre compte. Votre administrateur FASTR est la personne qui gère les comptes des utilisateurs de FASTR dans votre pays. Si vous ne parvenez pas à vous connecter, contactez votre administrateur FASTR.

## Comment savoir si une connexion vient de vous

L'e-mail indique le type d'appareil, le système d'exploitation (par exemple Windows ou Android), l'adresse IP (un numéro qui identifie la connexion internet), le lieu et la méthode de connexion. La connexion vient de vous si l'e-mail est arrivé peu après votre propre connexion à FASTR, et si le type d'appareil et le système d'exploitation correspondent à l'appareil que vous avez utilisé.

## Si vous recevez de nouveau cet e-mail

FASTR envoie cet e-mail chaque fois qu'il ne reconnaît pas l'appareil depuis lequel vous vous connectez. Vous pouvez donc le recevoir de nouveau. Avant d'appuyer sur le bouton, déterminez si la connexion vient de vous.

Si la connexion vient de vous, vous n'avez rien à faire. N'appuyez pas sur le bouton, car il ne sert pas à confirmer que la connexion vient de vous. Si elle ne vient pas de vous, ou si vous avez un doute, appuyez sur le bouton, puis [changez votre mot de passe](#la-connexion-ne-vient-pas-de-vous) et informez votre administrateur FASTR.
